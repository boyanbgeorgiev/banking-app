# Checkpoint 2 — Обзор и план

## Цел

Checkpoint 2 изисква **минимум 4 работещи функционалности** от планираните 10, имплементирана класова йерархия, проект, който **компилира и стартира без грешки**, и **минимум 5 commits** в git историята.

## Текущо състояние на репото

| Нещо | Статус |
|------|--------|
| Git commits | 2 (трябват още 3+) |
| Код | Няма — само README.md |
| Структура на папки | Няма |

## Какво трябва да се направи

1. Създай C++ файловете с класовата йерархия
2. Имплементирай минимум 4 функционалности
3. Направи поне 5 смислени commits (разбити логически)
4. Проектът да компилира и стартира

## Функционалности, които ще са имплементирани (≥4)

1. **Управление на сметки (CRUD)** — създаване на CheckingAccount и SavingsAccount
2. **Депозит и теглене** — с валидация
3. **Превод между сметки** — атомарна операция
4. **История на транзакциите** — запис и извеждане
5. **Справка за баланс** — текущ баланс на сметка
6. **Управление на клиенти** — добавяне, търсене, листване
